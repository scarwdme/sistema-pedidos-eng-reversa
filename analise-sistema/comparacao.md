# Comparação: Sistema Real vs Sistema Didático
 
## Parte 5 – Comparação com Sistema Didático
 
### Tabela Comparativa
 
| Critério | Sistema Real (Pizzaria Tropykaly Tibiquari) | Sistema Didático | Diferença |
|----------|---------------------------|------------------|-----------|
| **Arquitetura** | Camadas (Web tradicional + possível API) | Camadas básicas monolíticas | Sistema real mais estruturado |
| **Coesão** | Alta - classes focadas | Variável - muitas classes com múltiplas responsabilidades | Real superior |
| **Acoplamento** | Médio/Alto - Pedido acoplado a múltiplos serviços | Alto - forte dependência entre classes | Real melhor encapsulado |
| **Organização** | Bem estruturada em módulos (Produto, Pedido, Cliente) | Desorganizada - funcionalidades espalhadas | Real muito melhor |
| **Flexibilidade** | Moderada | Baixa - mudanças em um lugar afetam muitos | Real mais flexível |
| **Tratamento de Erros** | Robusto com validações em múltiplas camadas | inexistente | Real superior |
| **Integração com Externos** | Complexa | Não existe | Real muito mais complexo |
| **Padrões de Projeto** | Alguns implementados  | Nenhum | Real usa padrões |
| **Performance** | Otimizada (cache, lazy loading) | Sem preocupações de performance | Real melhor |
| **Segurança** | Alta (HTTPS, validação, proteção de dados) | inexistente | Real muito superior |
